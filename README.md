# FAQ Accordion

This is a simple FAQ Accordion made using HTML, CSS and JavaScript.

## About

The page contains some common questions about web development.
The answer to each question is hidden at first. Clicking a question
shows its answer, and clicking it again hides the answer.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- 8 FAQ questions
- Click to show the answer
- Click again to hide the answer
- Simple design
- Responsive layout

## Project Files

- index.html - Contains the FAQ questions and answers
- style.css - Handles the page design
- script.js - Controls the open and close action

## How to Run

1. Open the project folder.
2. Open `index.html` in a browser.
3. Click on any question.
4. The answer will appear below it.

## What I Learned

I learned how to handle click events in JavaScript and how
`classList.toggle()` can be used to show and hide HTML content.
